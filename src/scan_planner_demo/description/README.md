# Go2 模型来源

`xacro/` 与 `meshes/` 由原工作空间的 `go2_description` 功能包迁入；其
`package.xml` 声明 BSD-3-Clause。模型最初来自 Unitree Robotics 的
[`unitree_ros/robots/go2_description`](https://github.com/unitreerobotics/unitree_ros/tree/master/robots/go2_description)。
本项目仅调整资源路径并加入 Gazebo 三维里程计插件，保留原作者与许可。
许可全文见 [LICENSE-BSD-3-Clause.txt](LICENSE-BSD-3-Clause.txt)。
